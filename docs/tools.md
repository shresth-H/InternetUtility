# Tool Registry & Catalog

## 1. Client-Side Tools (19 Tools)

These run 100% inside the user's browser with zero network transmission.

### A. Calculators (8 Tools)
- `emi-calculator`: Computes monthly EMI, total interest, total payment, and 12-month schedule table.
- `sip-calculator`: Computes total investment, expected returns, and maturity value.
- `cagr-calculator`: Computes compound annual growth rate and total returns.
- `gst-calculator`: Computes GST inclusive and exclusive tax breakdowns.
- `percentage-calculator`: Computes percentage of values, percentage changes, and differences.
- `age-calculator`: Computes exact age in years, months, days, and total days.
- `date-calculator`: Computes calendar days, weeks, and business days between dates.
- `unit-converter`: Converts units across length, weight, and temperature.

### B. Text Utilities (5 Tools)
- `word-counter`: Real-time word, character, sentence, and reading time counter.
- `character-counter`: Character count with and without whitespace.
- `case-converter`: Converts between UPPERCASE, lowercase, Title Case, camelCase, snake_case, and kebab-case.
- `remove-duplicate-lines`: Deduplicates text lines preserving initial order.
- `text-diff`: Side-by-side text difference comparison.

### C. Developer Tools (6 Tools)
- `json-formatter`: Formats JSON with customizable 2-space, 4-space, or tab indentation.
- `json-validator`: Validates JSON syntax and provides pinpoint error line reporting.
- `jwt-decoder`: Decodes and inspects JSON Web Token headers, payloads, and timestamps.
- `uuid-generator`: Generates random RFC4122 version-4 UUIDs with batch creation.
- `base64-encoder`: Encodes and decodes UTF-8 text strings to and from Base64.
- `url-encoder`: Encodes and decodes URL components and query parameters.

## 2. Real Server-Side File Processors (15 Tools)

These tools use the asynchronous storage and processing engine to produce real converted binary outputs.

### A. PDF Manipulation (8 Tools)
1. `pdf-to-word`: Converts PDF document content into a valid, editable Microsoft Word `.docx` package.
2. `word-to-pdf`: Converts Word documents into clean, standard PDF documents.
3. `merge-pdf`: Combines multiple PDF files into a single unified document.
4. `split-pdf`: Extracts page ranges or slices PDF pages into separate documents.
5. `compress-pdf`: Compresses PDF object streams, metadata, and cross-reference tables.
6. `pdf-to-jpg`: Renders PDF pages to high-resolution JPEG images.
7. `jpg-to-pdf`: Embeds JPEG/PNG images into standardized PDF document pages.
8. `rotate-pdf`: Rotates all PDF pages by 90 degrees clockwise.

### B. Image Processing (7 Tools)
9. `resize-image`: Resizes images with aspect ratio preservation using Sharp.
10. `compress-image`: Optimizes JPEG, PNG, WebP, and AVIF file sizes.
11. `jpg-to-png`: Converts JPEG images to lossless PNG.
12. `png-to-jpg`: Converts PNG images to JPEG with white background flattening.
13. `webp-converter`: Bidirectional conversion between standard images and WebP format.
14. `crop-image`: Crops images to focused regions or standard aspect ratios.
15. `rotate-image`: Rotates images 90/180/270 degrees with orientation metadata normalization.
16. `remove-image-metadata`: Strips all EXIF, IPTC, and location metadata.
17. `generate-thumbnail`: Generates square cover thumbnails for previews.
18. `background-remover`: Isolates foreground subjects and removes image backgrounds.
