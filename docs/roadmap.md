# Product Roadmap & Growth Strategy

## Phase 1: MVP & Core Foundation (Completed)
- [x] Next.js 16 modular monolith with npm workspaces monorepo.
- [x] Tool Engine and central registry (`defineTool`).
- [x] 34 initial tools across 5 categories (Calculators, Text, Developer, PDF, Image).
- [x] Pure deterministic financial & math calculation engine with unit tests.
- [x] Browser-first privacy architecture for client utilities.
- [x] Server-side file upload & asynchronous job queue simulation.
- [x] Programmatic SEO system (clean URLs, metadata, schema.org JSON-LD, breadcrumbs, sitemaps).
- [x] Educational "Learn" articles linking tools and concepts.

## Phase 2: Scale Tools & Indian Utilities (Next)
- [ ] Add 30+ regional & specialized calculators:
  - Income Tax Calculator (Old vs New Regime)
  - HRA Exemption Calculator
  - Gratuity Calculator
  - EPF & PPF Calculator
  - Fixed Deposit (FD) & Recurring Deposit (RD) Calculator
- [ ] PDF Tools:
  - Live PDF merging and splitting via WebAssembly / `pdf-lib` in-browser
  - OCR text extraction engine
- [ ] Image Tools:
  - Canvas-based visual image cropper and resizer

## Phase 3: AI Intelligence Layer & Accounts
- [ ] Contextual AI explanations for all calculators ("Explain my result", "Is this CAGR good?").
- [ ] AI text enhancement (summarize, rewrite, tone change).
- [ ] User accounts for saved calculation history, favorites, and cloud file history.
- [ ] Export calculation reports to formatted PDF and Excel sheets.

## Phase 4: Monetization & Public APIs
- [ ] Pro tier subscriptions (larger file uploads, batch conversions, unlimited AI tokens).
- [ ] Public REST API with rate-limited API keys for developers.
- [ ] Browser extension and PWA offline support for calculators and developer utilities.
